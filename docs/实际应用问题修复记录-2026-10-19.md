# 实际应用问题修复记录

本轮基于 2026-10-19 检查报告修复已定位的软件缺陷。按用户要求，**YOLO 类别编号与类别表的映射逻辑保持原样**；仅修复标签文件重名和完整导出查询，不更改模型权重或训练数据。

## 已实施

| 范围 | 修改后的行为 |
| --- | --- |
| 清理预检 | 所有清理路径贯穿 dry_run；预检不删记录、不改文件、不写审计；避免重复统计释放空间；移除重复注册的清理路由 |
| 回收站 | 保存原目录及真实入站时间；旧条目兼容；未知时间保守保留；恢复视频到 results；恢复冲突返回409，不覆盖现有文件 |
| 并发文件安全 | 回收前复查引用与租约；图片结果、视频输出在生成至事务完成期间保持文件租约 |
| 视频计数 | 完整跟踪才提供轨迹数；跟踪降级或缺少编号时，unique_objects=null、unique_count_valid=false，并说明累计框口径；旧视频未知口径不伪造有效计数 |
| 视频任务 | 原子认领连接所有权；第二条连接只拒绝自己；被认领任务不被容量/TTL回收；取消时等待正在执行的原生工作结束 |
| 模型重载 | 图片与视频模型一起原子切换，失败保留原模型；运行中的视频阻止重载；记录实际加载权重版本 |
| 参数与暂停 | 一次性验证配置后更新；拒绝非法整数与布尔值；视频冻结输出尺寸、跳帧等参数；保存置信度变化时间线；暂停不丢失已消费帧号 |
| 视频导出 | 使用本机可用的 H.264 编码器生成 yuv420p MP4；奇数分辨率安全补齐；编码失败不提供损坏下载链接；前端有失败提示与下载入口 |
| 数据完整性 | 图片/视频主记录、明细、类别及帧统计统一事务；失败回滚；报告和标签使用完整明细查询，取消隐式500条截断 |
| 标签文件命名 | 生成后缀时检查所有已占用名字，避免 a.jpg、a_2.jpg、a.png 相互覆盖；类别编号逻辑不动 |
| 图片请求 | 检测中冻结选择、重置及阈值；响应序号校验防旧请求覆盖新内容；格式与大小提前校验，后端继续做最终校验 |
| 旧记录 | 图片正确回填并显示 total_objects；旧视频不将默认0当成已确认轨迹数 |
| 类别分布 | 每份源图片只取最新成功分析，再按检测日期筛选；不混入视频；明确不同图片仍可能拍到相同目标 |
| 趋势图 | 日/周类别趋势与主趋势采用相同桶；缺测数据保留null并断线；筛选切换期间清除旧展示 |
| 指标解读 | 用ln(S)理论上限和分布均匀度辅助阅读；移除真实物种、个体总量、生态质量和“置信度就是准确率”的推断 |
| 报告追溯 | 保存源文件哈希、实际权重哈希、设备、使用参数及计数模式；旧记录缺失信息显示未保存，不借用当前配置或其他记录信息 |
| 报告展示 | PDF与标签入口明确只含成功图片；PDF占比条使用矢量绘图避免缺字；重新渲染并检查了两页报告 |
