cURL 示例 — 图片检测

curl -X POST "http://127.0.0.1:8000/api/detect/image" ^
     -F "file=@photo.jpg"

Python 示例 — 图片检测

import requests

BASE = "http://127.0.0.1:8000"

with open("photo.jpg", "rb") as fp:
    resp = requests.post(
        f"{BASE}/api/detect/image",
        files={"file": fp},          # 注意: 字段名是 file(单数)
    )

data = resp.json()
if data["success"]:
    print("检出目标:", data["data"]["total"])
    for det in data["data"]["detections"]:
        print(det["class_name"], round(det["confidence"], 3))

Python 示例 — 批量图片检测

import requests

BASE = "http://127.0.0.1:8000"
files = [
    ("files", open("a.jpg", "rb")),   # 批量接口字段名是 files(复数)
    ("files", open("b.jpg", "rb")),
]
resp = requests.post(f"{BASE}/api/detect/images", files=files, data={"conf": 0.25})
result = resp.json()["data"]
print(f"成功 {result['success_count']} / 失败 {result['failed_count']}")
print("批次 record_ids:", result["record_ids"])
